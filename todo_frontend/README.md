# Ocean Tasks - Simple Todo App (React)

A modern, minimalist todo app following the "Ocean Professional" theme. Add, edit, complete, and delete tasks with smooth interactions. Data persists in localStorage.

## Run locally
- npm start
- App runs on http://localhost:3000

## Features
- Add todos with Enter or Add button; empty submissions prevented
- Inline edit with Enter/Save and Cancel
- Delete with minimal confirmation
- Toggle complete
- Persist to localStorage
- Responsive single-column layout
- Ocean Professional theme: primary #3b82f6, secondary #64748b, success #06b6d4, error #EF4444, background #f9fafb, surface #ffffff, text #111827, subtle gradients & shadows

## Project structure
- src/components/Header.jsx
- src/components/TodoInput.jsx
- src/components/TodoList.jsx
- src/components/TodoItem.jsx
- src/styles/theme.css
- src/index.css
- src/App.js

No backend required. No environment variables needed.
